A from-scratch, dependency-free reimplementation of the makefun-site 1.0.0
static site generator in a single `solve.js`, written to answer byte-for-byte
identically on every case while spending far less CPU time: single-pass inline
rendering with bulk escaping, cached slug computation, offset-based front
matter scanning and a hand-rolled template engine. `main.ts` is the harness
driver: it reads the cases, answers each with `run()` and writes the answers.
